# Vue Dynamic List of Posts

A Vue.js application for managing posts and comments using the Mate Academy API.

## Demo

[Live Demo](https://luchali.github.io/vue_dynamic-list-of-posts/)

## Features

- User login and registration
- Display posts of the current user
- Create new posts
- Edit existing posts
- Delete posts
- Open post details in a sidebar
- Load comments from the API
- Add new comments
- Delete comments
- Form validation
- Loading states while waiting for API responses
- Error handling for API requests
- Responsive UI with Bulma

## Technologies

- Vue 3
- JavaScript
- Vite
- Axios
- Bulma
- Font Awesome
- Mate Academy API

## Getting Started

Clone the repository:

```bash
git clone https://github.com/luchali/vue_dynamic-list-of-posts.git
```

Go to the project folder:

```bash
cd vue_dynamic-list-of-posts
```

Install dependencies:

```bash
npm install
```

Run the project locally:

```bash
npm run dev
```

## Build

To create a production build:

```bash
npm run build
```
