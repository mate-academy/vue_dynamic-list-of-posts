# Vue Dynamic List of Posts

Simple Vue 3 + TypeScript application for managing posts and comments.

## Live Demo
[ https://nazarii84.github.io/vue_dynamic-list-of-posts/]

## Tech Stack
- Vue 3 (Composition API)
- TypeScript
- Vite
- Bulma
- ESLint

## Features
- View posts of current user
- Create new post
- Edit post
- Delete post
- View comments
- Add comment
- Delete comment
- Sidebar layout with responsive behavior

## Installation

```bash
npm install
npm run dev
